# Bounded Task Brief

Use this template to give an AI agent the relevant context for one bounded task. Reference approved requirements rather than creating a competing source of truth. Replace the placeholders and remove anything that does not apply.

```text
Goal:
[What should change? Reference the approved task or requirements.]

Current observation:
[What happens now? Include a reproduction or evidence reference.
Separate observations from unconfirmed explanations.]

Relevant sources:
[Files or documents to start with, and why each matters.]

Constraints:
[What must remain unchanged? What is outside this task?
Ask before expanding the approved scope.]

Acceptance criteria:
[Observable outcomes and the behavior that must still work.]

Before making changes, read the available relevant sources. Summarize
the goal, boundaries and acceptance criteria. Identify missing information,
unavailable sources or conflicts. Do not invent missing facts.
Do not edit files yet; wait for my approval of the next bounded step.
```

Review the agent's interpretation against the sources before approving implementation. The source list is a starting point, not a ban on finding other relevant information. This brief supports the approved workflow; it is not a replacement for PRD, PLAN or TASK.
