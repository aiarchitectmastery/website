AAM Prompt Pack

Every prompt in the AAM Agent Workflow, in one free pack by email. Each prompt supports one step of the PRD → PLAN → TASK → IMPLEMENTATION methodology. You decide when to run it, and you review the result yourself before you keep it.

Who it's for: Experienced developers who work with an AI coding agent such as GitHub Copilot and want repeatable prompts with human checkpoints.

In the pack today:

  • Agent guidance review prompts: review the Copilot instructions, custom agents and prompt files your project already has, one approved change at a time, without losing responsibilities, permissions or mandatory checks. Includes the exact four prompts from the AAM agent guidance video.

The pack follows the AAM Agent Workflow releases. The link in your email always shows the current set of prompts, with a short guide to each one.

Limits: The prompts don't enforce tool permissions or guarantee performance gains. Use your environment's permission controls, and run the checks on a harmless task.
