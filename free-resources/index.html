Agent Guidance Review Prompts

The prompts shown in the AAM agent guidance video. Use them to review the Copilot instructions, custom agents and prompt files your project already has, without losing responsibilities, permissions or mandatory checks.

Who it's for: Experienced developers whose project already has agent guidance, and who want to change it deliberately, one reviewed step at a time.

Where it fits: These prompts apply the TASK and IMPLEMENTATION steps of the PRD → PLAN → TASK → IMPLEMENTATION methodology to your existing agent guidance: you approve one bounded change, then inspect the diff and verify the agent's behavior yourself before you keep it.

  • Analyze before you change anything: the agent proposes small named stages and edits nothing
  • Approve one bounded stage: you name the exact files and the boundaries that must stay
  • Verify the result yourself: positive and negative controls in fresh conversations
  • The exact four prompts from the video, in the appendix

Limits: The prompts don't enforce tool permissions or guarantee performance gains. Use your environment's permission controls, and run the checks on a harmless task.
